# Soil

The `dssat.soil` package contains the soil water balance and stub modules for nitrogen, phosphorus, and organic matter.

## Soil Water Balance

Implements the **Ritchie tipping-bucket** method with SCS runoff, potential ET (Priestley-Taylor or Penman-Monteith), and drainage.
